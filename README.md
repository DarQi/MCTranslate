# MCTranslate

Десктопное приложение для перевода квестов и языковых файлов в модпаках Minecraft.

## Поддерживаемые форматы

- **FTB Quests** (`config/ftbquests/**/*.snbt` — встроенный в квесты текст и отдельные языковые файлы `lang/en_us.snbt`).
- **Better Questing** (`config/betterquesting/DefaultQuests.json`).
- **Диалоги NPC и сюжетные диалоги** (`dialogue.*` в ресурсах модпаков и диалоговые JSON-файлы датапаков, например в **Prominence™ II: Hasturian Era**).
- **Деревья талантов Puffish Skills** (`config/puffish_skills/categories/**/category.json` и `definitions.json` с защитой кастомных Unicode-иконок навыков).
- **Языковые файлы модов и сборок** (`en_us.json` и `en_US.lang` из папок `kubejs/assets`, `resources`, `config/openloader`, `global_packs`, `config/paxi`, а также напрямую из `.zip` ресурспаков Paxi и `.jar` файлов модов сборки).

## Основные возможности

- **Вкладки по категориям (`Все`, `Квесты`, `Диалоги`, `Таланты / Lang`):** удобная фильтрация файлов и автоперевод выбранной вкладки (например, только диалогов).
- **Автоматическое сканирование сборки** (включая чтение `.jar` и `.zip` архивов и вложенных `META-INF/jars/*.jar`) или открытие отдельных файлов `.snbt`, `.json`, `.lang`.
- **Сохранение структуры файлов:** собственный парсер SNBT/JSON заменяет только переведённые строковые литералы по их точным смещениям, не затрагивая ID, координаты, типы данных (`1b`, `4L`, `[I; ...]`) и форматирование исходного файла.
- **Защита форматирования Minecraft:** цветовые коды (`&a`, `§6`, `&r`), плейсхолдеры (`{@pagebreak}`, `%s`, `%1$d`) и иконки кастомных шрифтов (`Private Use Area`) защищаются перед отправкой в переводчик и проверяются после перевода.
- **Два режима работы:** ручной построчный перевод и пакетный автоперевод (для текущего файла, текущей вкладки или всей сборки).
- **Поддерживаемые переводчики:**
  - Google Translate (пакетная отправка до 35 строк за запрос, без API-ключа).
  - DeepL (Web JSON-RPC без ключа, официальный API Free/Pro или зеркало DeepLX).
  - MyMemory (без API-ключа).
  - Любая OpenAI-совместимая нейросеть по API (DeepSeek V3 / R1 DeepThink, OpenAI, Gemini, OpenRouter, локальная Ollama) с выбором модели из списка или загрузкой списка моделей с сервера (`GET /models`), настройкой стиля перевода и параметров генерации.
- **Глоссарий терминов:** настраиваемый словарь терминов Minecraft.
- **Автосохранение сессии:** весь прогресс сохраняется автоматически на лету (в профиле пользователя и в папке `.mctranslate/progress.json` внутри сборки) и восстанавливается при следующем запуске.
- **Безопасная запись и автоупаковка в ресурспак:** прямое применение перевода в сборку с созданием резервных копий в `.mctranslate/backups/` и автоматической генерацией локализационного ресурспака `MCTranslate_RU` (и датапака `MCTranslate_RU_Data`) для диалогов и строк модов.
- **Темы оформления:** тёмная и светлая.

## Готовая сборка

Готовый архив `MCTranslate.zip` для Windows x64 (не требует установки Node.js) доступен в разделе **Releases** этого репозитория. Достаточно распаковать архив и запустить `MCTranslate.exe`.

## Запуск из исходного кода

Требуется установленный Node.js (v18 и выше).

```bash
npm install
npm start
```

## Структура проекта

- `src/main.js` — главный процесс Electron, работа с файловой системой, настройками и бэкапами.
- `src/preload.js` — мост IPC между главным процессом и интерфейсом.
- `src/core/snbt.js` — парсер форматов SNBT и JSON с сохранением байтовых позиций строк.
- `src/core/extractors.js` — извлечение переводимых строк и сборка переведённых файлов.
- `src/core/scanner.js` — поиск файлов квестов и локализации в папке модпака.
- `src/core/translate.js` — модули перевода (Google, DeepL, MyMemory, OpenAI-совместимые LLM) и защита спецсимволов.
- `src/renderer/` — интерфейс приложения (`index.html`, `styles.css`, `app.js`).
